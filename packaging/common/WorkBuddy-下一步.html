Trimate：把一个 ZIP 发给 AI

当前只交付一个文件：Trimate-V1.2.1.zip。将它作为附件发到支持本机操作的 WorkBuddy 或 GPT/Codex 本地 Work 对话，并说“开始使用 Trimate”。通用 Agent 与场景 Skill 已在包内，不需要另外导入 WorkBuddy Skill。

已有本机连接

AI 应先检查 Trimate MCP 是否可用。已经连接时，可以直接查询你的私有训练数据，无需重复安装。

首次连接

如果你使用的 AI 能操作本机文件和命令，上传 ZIP 后它会运行包内的自动安装入口，建立空白个人档案并配置当前宿主的 MCP。宿主可能要求重载、信任或系统授权；佳明、高驰账号登录由你在本机或官方页面完成。普通网页对话上传 ZIP 不会自动访问电脑里的数据。

ZIP 不含运动数据、设备密码或密钥。未成功连接本机 MCP 时，AI 可以先根据你主动提供的信息讨论目标和训练，但不能声称已读取你的个人数据库。
