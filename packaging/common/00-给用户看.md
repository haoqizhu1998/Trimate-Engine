# 把这个 ZIP 发给 AI

把**整个压缩包**拖入支持本机文件与命令的 WorkBuddy 或 GPT/Codex 本地 Work 对话，发送“开始使用 Trimate”。AI 会先自动建立本机空档案并配置当前宿主的 MCP，再询问你的运动目标。设备登录和宿主授权界面仍需你自己完成。

这份包包含 Trimate 的通用 Agent、Skill 与本机安装文件，**不含任何人的运动数据或账号**。首次连接时，AI 可运行包内自动安装流程；安装完成后可能需要重载宿主，实际工具可用后才能读取本机数据。普通 GPT 网页对话上传 ZIP 只能用于对话体验，不能自动安装电脑程序或连接本地 MCP。

如果 AI 没有读取到压缩包，请让它查看 `00-请AI先读.md`；若平台不支持 ZIP，改用 WorkBuddy 本地任务或 GPT/Codex 本地 Work。不要把设备密码或 API Key 发到聊天中。
