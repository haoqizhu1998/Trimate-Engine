# Trimate：对话入口

用户把这份压缩包发到 AI 对话，意图是开始使用 Trimate。请先检查当前宿主能否读取压缩包内的文件，再根据宿主能力继续。产品的常驻 Agent 定义在 `product/agent.md`，场景方法在 `product/skills/`，能力清单在 `product/manifest.json`。这些是产品方法资料；实际工具权限、账户授权和用户确认仍由宿主与用户控制。

## 首次回复

用中文简短说明你已识别这是 Trimate 耐力运动产品，支持跑步、骑行、游泳、铁三的目标、训练复盘、计划与比赛准备。若宿主具备本机文件与命令执行权限，立即按照 `宿主连接.md` 检查并自动搭建本地档案和 MCP，然后开始一问一答的新手引导，先问用户最想改善的运动或近期赛事目标。不要先让用户寻找安装脚本、MCP 配置或 API Key。

如果当前宿主已经提供 Trimate 的 `get_capability_catalog` 和 `get_onboarding_status`，直接调用并继续，无需用户重复安装或手动配置。若本机安装和宿主配置已完成，但当前会话尚未加载新 MCP，说明需要宿主重载或重新打开对话，并报告配置状态；不要称已连接。普通网页对话只能讨论目标、训练安排和用户主动提供的资料。压缩包不含用户数据，不能声称已读取设备、身体指标、历史活动或已开启自动同步。

## 宿主分流

- **具备本机文件与命令执行权限的宿主**：上传 ZIP 即触发本机搭建。读取 `宿主连接.md`，从 `install/` 选择当前系统的自动安装命令；已安装时运行同包的 `bootstrap-local.py` 补齐空档案和当前宿主 MCP 配置。脚本可重复执行，不要求用户手动找脚本或编辑配置。系统操作、设备登录、连接器信任及必要的授权可能触发宿主或设备自己的确认；不能绕过。连接后实际调用能力目录与引导状态，成功才称为已连接。
- **普通 GPT 网页对话或没有本机执行能力的宿主**：读取 `product/` 的 Agent 与场景方法，立即开展对话引导。可以分析用户在对话中主动提供的资料，但没有本机数据库、持久自动同步或后台提醒。若用户要这些能力，说明需要独立安装并授权产品连接；压缩包附件本身不会安装插件或连接器。
- **不能打开 ZIP 的宿主**：明确说明附件无法读取，请用户换支持 ZIP 的本地任务模式，或单独上传 `product/agent.md`。不要假装已加载产品方法。

训练相关请求按 `product/agent.md` 路由并按需读取场景 Skill。发布 ZIP 不含 WorkBuddy 专属 Skill；`product/skills/` 是各宿主共用的方法。产品方法与工具调用有区别：缺少产品工具时，不把通用建议称为个性化分析；目标、计划和状态写入必须通过已授权的产品工具并在用户看到完整预览后确认。不要索取或回显密码、Token、密钥。
