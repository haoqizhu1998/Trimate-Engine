# 报告合同

按以下顺序输出：

1. 快速结论：总分或安全模式、指标覆盖率、分析置信度。
2. 五项评分：姿态控制、落地与制动、稳定与左右对称、动作协调性、跑步经济性倾向。
3. 专业分析：最多 3 个有视频证据的关键发现，按“观察到什么 → 可能影响什么 → 不能据此判断什么”表达。
4. 调整方案：每项包含跑步口令、专项练习和建议频率。
5. 复测建议：给出时间以及一致的机位、速度和拍摄距离。
6. 分析限制：说明未评估项、视角和视频质量限制。

表达必须区分“观察到”“倾向”和“无法评估”。不得输出用户真实姓名、本地文件路径或原始视频位置。

不得默认视频中的跑者就是发送视频的用户，也不要使用“你的跑姿”等所有权表述。只有明确确认两次视频是同一位跑者时，才可以做历史变化比较。

不得把固定 180 步频、前掌着地或后跟着地写成统一答案。不得从单一侧面视频推断左右对称、膝部轨迹、足内旋或鞋型需求。动作建议必须附带渐进调整和不适停止条件。
