# 夜间 HRV 与当日训练状态：产品方法

## 证据边界

- 佳明兼容设备在睡眠期间测量 HRV，呈现昨晚均值、七天滚动均值及个人基线区间。其个人基线通常需要约三周连续夜间佩戴。不同测量协议和设备的绝对值不宜直接比较：[Garmin HRV Status](https://www.garmin.com/en-IE/garmin-technology/health-science/hrv-status/)。
- 澳大利亚体育委员会建议优先看七天滚动均值而非单次读数；七天窗口至少需要三次测量。解释时还要考虑训练阶段、负荷、睡眠、营养和其他恢复因素：[AIS HRV 最佳实践](https://www.ausport.gov.au/ais/position_statements/heart-rate-variability)。
- 一项 40 名休闲耐力跑者的随机试验提示，用 HRV 调整高强度课时机可能有益；研究不能证明任意腕表的单晚 HRV 就能判断当天能否完成训练，也不能外推为比赛成绩保证：[Vesterinen 等，2016](https://pubmed.ncbi.nlm.nih.gov/26909534/)。

## Trimate 当前实现

1. 佳明中国区同步时分别保留 `last_night_avg_ms` 与 `weekly_avg_ms`。只有明确标为昨晚均值的记录参与逐日比较；历史版本中可能由周均值回填的 `hrv` 字段不参与新分析。
2. 日报和周报展示最近一晚的日期、数值与是否为报告当日；最近七天有至少三晚时展示七天均值，前 21 天有至少七晚时展示参考均值及数值差异。前 21 天均值是**产品参考**，不是佳明的个人基线，也不代表统计显著变化。
3. 同一比较只使用同一来源的夜间值，缺失、过期、来源切换和样本不足均明示。HRV 单独不改变安全等级、课表或当日训练选择；训练决策预览只把它作为附加证据，与疼痛、疾病、疲劳、睡眠、静息心率和近期负荷一起核对。
4. 新版算法不会把旧版语义不明的历史 `hrv` 字段自动视作夜间读数。旧数据需重新同步并产生明确口径后才会进入新趋势；无数据时保持缺失，不制造“状态良好”。

## 未实现

当前未复制佳明的个人基线区间、HRV 状态标签或训练准备度算法；未从原始 RR 间期计算 lnRMSSD，也未验证不同设备间的测量等价性。因此不输出“恢复好/差”“可以加量”等单一 HRV 裁决。
