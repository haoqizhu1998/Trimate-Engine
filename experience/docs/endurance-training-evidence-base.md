# 耐力训练证据库

版本：`0.2.0`  
最后检索：`2026-11-11`

本文件记录 [Trimate 循证有氧耐力训练方法](endurance-training-methodology.md) 的公开来源、采用范围和限制。它不是教材副本，也不保存付费内容。

## 来源治理

- 优先保存官方页面、DOI、PubMed/PMC 和出版社页面。
- 书籍只使用合法获得的元数据、目录、公开节选或所有者提供的正版内容。
- 新研究不能仅因发布时间新就自动覆盖共识；要看研究设计、人群和项目适用性。
- 每条工程规则应能追溯到来源、适用人群和不确定性。
- 至少每 12 个月复核一次；安全共识、重大系统综述或项目规则变化时提前复核。

## 框架来源

### F1 — RRCA Coaching Certification Program

- 类型：协会官方课程框架，C 级。
- 地址：https://www.rrca.org/programs/coaching-certification/
- 采用：教练伦理、运动生理、计划设计、训练类型、跑姿、营养、心理、伤病识别和环境因素的能力边界；Level 2 的周期化、疲劳管理和达峰概念。
- 限制：公开网页不是完整课程教材；RRCA 重点是成人长跑，不能直接覆盖完整骑行、游泳和铁三方法。

### F2 — USA Triathlon, *Complete Triathlon Guide*

- 中文版：《铁人三项运动全书》第 2 版，美国铁人三项协会编著，人民邮电出版社，2022，ISBN `9787115595874`。
- 原版公开页面：https://us.humankinetics.com/products/complete-triathlon-guide
- 类型：国家协会编著的综合教练教材，C 级。
- 采用：公开目录提供铁三方法覆盖图，包括赛季计划、特殊人群、柔韧与力量、游骑跑训练、恢复与过度训练、生理学、减量、专项技术、换项、竞赛策略、心理、伤病、营养、水合和长期发展。
- 限制：当前知识库没有保存教材全文；仅凭目录不能推断具体剂量。具体处方需要 A/B 级证据和运动员反馈校验。

## 负荷、恢复与安全

### E1 — IOC 训练负荷与伤病/疾病共识

- 来源：[伤病风险 Part 1](https://doi.org/10.1136/bjsports-2016-096581)、[疾病风险 Part 2](https://doi.org/10.1136/bjsports-2016-096572)。
- 类型：国际共识，A级。
- 采用：同时监控外部负荷、内部负荷、主观恢复、心理/生活压力和健康症状；个体化管理负荷变化；没有单一指标能识别所有不良适应。
- 工程约束：不同负荷工具和量纲保留来源，只在同口径历史中比较；无个人心率锚点时不使用绝对心率阈值制造精确分数；不把训练后疲劳或 Garmin Training Effect 擅自换算成 session-RPE。
- 限制：部分 ACWR 和“10%”表述主要来自团队项目的早期观察研究，不应直接变成耐力运动硬阈值。

### E2 — ACWR 2026 系统综述与多层荟萃分析

- 来源：https://pubmed.ncbi.nlm.nih.gov/42662491/
- 类型：团队项目系统综述与荟萃分析，A级但跨项目外推降一级。
- 采用：ACWR 只能作为个体化、多指标负荷系统中的情境指标。
- 限制：研究异质性很高，且主要是团队项目；不支持把 ACWR 当作独立因果或伤病预测模型。

### E3 — IOC 2023 REDs 共识

- 来源：https://bjsm.bmj.com/content/57/17/1073
- 类型：国际共识，A级。
- 采用：把低能量可用性、健康和表现风险纳入训练可用性判断；疑似风险时不通过继续加量解决。
- 限制：筛查与诊断需要合格专业人员；Agent 只识别风险并转介。

### E15 — 跑步训练参数与损伤系统综述

- 来源：https://pubmed.ncbi.nlm.nih.gov/34478518/
- 类型：系统综述，A级；涵盖不同水平跑者。
- 采用：现有证据并不一致支持一个通用的周量或周增幅安全阈值。产品因此用个人连续训练记录、主观状态与时间约束形成可复核预算，并将增长参数明确标为工程启发式。
- 限制：研究的人群、训练量定义和损伤定义差异大；不能据此证明某种预算算法能预防伤病，也不能把跑步结论直接套到骑行或游泳。

### E16 — 高水平耐力运动员长期训练发展综述

- 来源：https://pubmed.ncbi.nlm.nih.gov/37178349/
- 类型：范围综述，B级；主要涉及高水平运动员。
- 采用：长期训练量往往呈非线性变化，支持把一次较轻周与持续能力区分开，并持续依据实际反应修订计划。
- 限制：样本少且运动水平高，不能直接决定业余运动员每周应增加多少分钟；Trimate 的短期回归与推进参数仍是待验证产品假设。

## 强度分布与周期化

### E4 — 跑步强度分布系统综述

- 来源：https://pubmed.ncbi.nlm.nih.gov/34749417/
- 类型：系统综述，A级。
- 采用：大量低强度配合少量中高强度通常优于阈值占比过高；同时使用主观与客观指标监控。
- 限制：强度区间和统计方法不同会改变“分布”结论，不能把综述中的比例写成个人固定处方。

### E5 — 2025 强度分布个体数据网络荟萃分析

- 来源：https://pubmed.ncbi.nlm.nih.gov/39888556/
- 类型：系统综述与个体数据网络荟萃分析，A级。
- 采用：不宣称极化式对所有耐力运动员普遍优于其他结构；训练水平和统计口径可能改变反应。
- 限制：干预通常不超过约 18 周，VO2max 和计时表现不能代表所有长期与赛事结果。

### E6 — 跑步周期化与强度分布综述

- 来源：https://pubmed.ncbi.nlm.nih.gov/29182410/
- 类型：系统综述，A级。
- 采用：金字塔式和极化式都可用于中长跑；避免默认阈值主导。
- 限制：纳入研究数量有限，训练方案和运动员水平存在差异。

### E7 — 训练有素骑手的周期化综述

- 来源：https://pubmed.ncbi.nlm.nih.gov/36640771/
- 类型：系统综述，A级。
- 采用：传统和区块周期化均可有效，不宣称存在适用于所有骑手的唯一最优模型。
- 限制：纳入研究较少，对完整赛季影响的证据有限。

### E8 — 耐力项目减量荟萃分析

- 来源：https://pubmed.ncbi.nlm.nih.gov/37163550/
- 类型：系统综述与荟萃分析，A级。
- 采用：赛前减少训练量、保留部分强度与频率；约 1–3 周和约 41%–60% 减量作为人群起点。
- 限制：不能把平均有效范围直接变成每位运动员的固定减量处方。

## 力量与跨项目训练

### E9 — 耐力运动员力量训练伞式综述

- 来源：https://pubmed.ncbi.nlm.nih.gov/40153564/
- 类型：系统综述的伞式综述，A级。
- 采用：力量训练可改善耐力表现和跑步经济性；加入计划时保护专项训练和恢复。
- 限制：纳入综述质量不一，最优剂量和不同人群反应仍不确定。

### E10 — 骑行重力量训练系统综述

- 来源：https://pubmed.ncbi.nlm.nih.gov/40632222/
- 类型：系统综述与荟萃分析，A级。
- 采用：重力量可能改善骑行效率、无氧功率和表现。
- 限制：结论证据确定性较低，不远程硬编码固定负荷或动作。

### E11 — 跑步与骑行交叉训练系统综述

- 来源：https://pubmed.ncbi.nlm.nih.gov/42267259/
- 类型：系统综述与荟萃分析，A级。
- 采用：骑行可作为控制跑步机械冲击的有氧补充；跨项目能力迁移需要保留专项刺激。
- 限制：纳入研究较少，不能建立通用 TSS 等价换算。

## 强度区间工程来源

### E12 — Joe Friel 阈值区间公开指南

- 来源：https://www.trainingpeaks.com/learn/articles/joe-friel-s-quick-guide-to-setting-zones/
- 类型：公开教练方法，C 级。
- 采用：跑步阈值配速七区、跑步/骑行专项阈值心率七区，以及按 FTP 计算的骑行功率六区；跑骑阈值心率分开计算。
- 工程约束：保存 `algorithm_key` 与 `algorithm_version`；百分比边界是处方语言，不等于独立测得的生理分界。整数心率与功率边界做连续取整，并同时输出 RPE 和谈话测试。
- 限制：区间体系不唯一；高温、疲劳、补给、地形和设备误差会改变当天内部成本。

### E13 — Coggan 骑行功率区间说明

- 来源：https://www.trainingpeaks.com/blog/power-training-levels/
- 类型：公开专项方法，C 级。
- 采用：FTP 作为骑行功率区间锚点；区间同时提供体感和用途。
- 限制：生理反应是连续谱，分区数量和边界具有方法学选择性；神经肌肉冲刺不能仅由 FTP 百分比精确定义。

### E14 — Swim Smooth CSS 训练目标

- 来源：https://blog.swimsmooth.com/p/understanding-training-zones
- 类型：公开游泳教练方法，C 级。
- 采用：CSS 作为游泳专项阈值锚点；轻松目标约 CSS +8–10 秒/100 米，稳定有氧目标围绕 CSS +6 秒/100 米，阈值目标围绕 CSS。
- 工程约束：Trimate v1 给目标范围而非单点；高强度不生成统一冲刺配速，必须结合重复距离、休息和动作稳定性。
- 限制：泳池长度、泳姿、技术水平与公开水域条件影响可比性；当前目标范围不是实验室生理分区。

## 方法更新规则

新增来源时记录：

```text
来源编号：
检索日期：
研究/机构：
人群与项目：
结论：
主要限制：
影响的现有规则：
需要修改的 Skill/测试：
复核人：
```

以下变化必须升级方法版本并增加测试：

- 医学安全门或转介标准变化。
- 强度区间定义、负荷算法或风险解释变化。
- 正式支持新的赛事或特殊人群。
- 改变训练计划、身体评估或单次反馈的核心决策顺序。
