# 跑姿与跑步建议证据规则

本文件约束跑姿分析、单次训练反馈、伤病风险、训练计划和训练营养中的跑步建议。目标是吸收稳定、可执行的原则，同时避免把经验文章中的固定数字或单一技术流派当成事实。

## 证据使用顺序

1. 当前用户自己的疼痛、恢复、训练历史和同条件基线。
2. 当前训练的客观数据与可见视频证据。
3. 运动医学、运动生理和生物力学研究中的稳定结论。
4. 教练或科普文章中的经验建议，只能作为待验证线索。

不同来源冲突时，采用更保守、个体化、可复测的建议。不要用一篇文章覆盖用户自己的长期反应。

## 可以进入产品的原则

- 跑姿目标是稳定、省力和可持续，不是复制统一外观。
- 优先减少明显跨步制动、过度上下起伏、躯干左右晃动和紧张摆臂。
- 头部与躯干保持稳定；需要前倾时从脚踝自然微倾，不用弯腰换取角度。
- 摆臂以放松、自然前后为主，明显横过身体中线时再提示调整。
- 步频和步幅随速度、身高、坡度、疲劳与个人习惯变化，只和用户自己的同配速基线比较。
- 脚落点应结合身体重心、胫骨角度和是否存在制动判断，不能只凭前掌、中足或后跟分类。
- 侧面视频主要看姿态、落地点和制动；正面或后方视频主要看左右稳定、膝部轨迹和骨盆控制。
- 视频指标与手表的步频、垂直振幅、触地时间等设备指标属于不同证据，只有同次、同速度时才可互相印证。
- 动作调整一次只改一个变量，从轻松跑短段开始，并观察小腿、跟腱、足底和膝部反应。
- 热天同配速下心率和体感可能升高，反馈与计划应降低配速执念，改用 RPE、谈话测试和补水策略。
- 训练中断、伤病或疾病恢复后，先恢复轻松有氧和规律，再恢复总量，最后加入强度。
- 长距离补给应在明显饥饿、低血糖感或后程崩溃前开始，并在训练中反复验证胃肠耐受。

## 不能作为默认规则

- 所有人都应该维持 180 步/分钟。
- 前掌或中足着地天然优于后跟着地，或换着地方式一定能减少伤病。
- 只看一段侧面视频即可判断左右对称、足内旋、膝内扣或鞋型需求。
- 单一关节角度、步频或脚落点可以直接证明伤病原因。
- 用 `220 - 年龄` 自动生成精确心率区间。
- 所有人适用固定周量增长百分比、固定恢复天数或固定比赛负荷区间。
- 仅凭视频或足型描述推荐支撑型、缓震型或竞速鞋。

## 来源与吸收范围

- [跑步的正确姿势与原理](https://zhuanlan.zhihu.com/p/78739205)：吸收动作阶段、减少制动、稳定躯干和放松摆臂；不采用统一步频与统一着地方式。
- [长距离跑步的正确动作分析：八个关键要素](https://www.scstar.com.tw/blogs/%E9%86%AB%E5%B8%AB%E5%B0%88%E6%AC%84-%E5%BE%A9%E5%81%A5%E5%B0%88%E7%A7%91/176982)：吸收多视角视频、动作稳定与设备数据互证；不把鞋型和着地方式建议直接写成诊断。
- [如何科学地进行跑步](https://zhuanlan.zhihu.com/p/661662084)：吸收热环境修正、动态热身、渐进回跑、补给演练和步频个体化；不采用固定心率公式、固定步频、简化训练负荷公式和缺少边界的营养建议。
