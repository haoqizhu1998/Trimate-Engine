# ADR 0011：有证据边界的成长画像与训练决策闭环

- 状态：已接受
- 日期：2026-10-27

## 背景

原有成长能力保存反馈、里程碑和样本相关性，但尚不能把用户的选择与实际反应连接成可追溯的下一次建议。模型宿主对话历史不能作为长期个人画像，单次设备指标或一次主观反馈也不能证明某种训练策略对个人有效。

## 决策

第一版从**每日训练选择**建立闭环：当前日报和主观 Check-in → 安全边界内的 `usual`、`easy`、`pause` 选项 → 用户确认 → 私有决策日志 → 用户报告的完成和感受 → 最近 90 天的成长画像 → 候选个体化适应 → 用户确认后只调整低风险日的默认推荐。目标和计划仍沿用现有确认与版本流程，不在此闭环中被静默改写。

成长画像是私有 SQLite 数据的即时投影，不是模型 Prompt 记忆。它区分已确认目标、已有计划、决策、用户报告的结果及同日是否有客观活动记录。设备活动只能说明记录存在，不能自动证明用户完成了所选方案。无匹配活动时，候选适应明确标注只基于用户报告。相关模式不是因果证据。

决策预览绑定运动员、当天报告、当前标准记录集合、已生效适应和当前决策版本。源数据变化后旧预览失效；确认时在事务中再检查记录集合。当天改选产生新决策，旧决策保留但退出当前画像。反馈支持乐观版本修订，跨运动员数据不可互用。候选适应同样绑定反馈和标准记录投影；只有反复出现的模式达到保守样本门槛时才出现，且必须经用户明确确认。适应可撤回，历史仍可审计。

安全优先级固定：`high` 只允许 `pause`；`moderate` 或 `unknown` 仅允许 `easy`/`pause`；`low` 可选三种。数据置信度不足时默认推荐 `easy`。已批准适应只能把低风险日默认推荐由 `usual` 调整为 `easy`，不能扩大安全允许选项、增加训练负荷、改写计划或提供医疗判断。

## 交付与边界

已交付独立的 `growth_decisions`、`growth_feedback`、`growth_adaptations` 私有表，宿主无关应用用例、七个 MCP 工具、Trimate场景 Skill 与合成集成测试。MCP 的预览/确认流程和草案哈希不能独立证明真人批准；远程开放写入仍需 ADR 0007 所述的身份和独立确认机制。

当前算法只识别一种保守的候选模式：最近 90 天**同为低风险日**的已完成反馈中，至少三次 `usual`、三次 `easy`，其中 `usual` 至少两次较差或运动后疼痛升高，`easy` 至少两次未变差且疼痛较低。它只是提示尝试较轻的默认建议，不能称为自我训练的模型或运动效果证据。更广泛的目标冲突、周期计划调整、偏好学习与真实前瞻评测以后单独演进。
