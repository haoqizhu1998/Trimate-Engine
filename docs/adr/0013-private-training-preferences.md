# ADR 0013：训练喜好属于用户私有画像

## 决策

产品 Skill 只定义如何询问、解释和运用训练喜好。用户明确确认的排课喜好保存在私有数据库的 `training-preference` 当前版本中，旧版本留作历史；`get_growth_profile` 将当前版本作为画像投影展示。自由文本记忆可供对话回顾，但不解析成可执行排课参数。

结构化字段包括专项关键课组织方式、是否跨项目穿插有氧、强度课和长课的偏好星期、默认重点项目。偏好变更经过 `get_training_preferences` → `preview_training_preferences` → 用户确认 → `confirm_training_preferences`；字段传 `null` 可清除。预览绑定用户和当前版本，竞争更新会被拒绝。所有值只在当前用户的私有库保存，不进入产品仓库或 Skill。

制定七天计划时，优先级为本次明确参数 → 已确认个人偏好 → 产品保守默认。调用者可关闭档案偏好读取；预览返回实际采用的约束、偏好版本和假设。已批准计划不被静默改写；偏好版本变化会使 `review_plan` 提示复核，`preview_plan_update` 复用原始输入重新计算草案。

专项按板块组织可作为已确认喜好记录。`preview_plan_blocks` 根据本次明确顺序，或已确认的板块偏好，生成 2–12 周重点项目轮换预测；仅首个七天生成可确认的逐日训练草案。后续周由 `review_plan` 和 `preview_plan_update` 重新读取当时证据、安全状态和偏好版本，再由用户确认；偏好版本变化要求重新预览板块。它不提供自动加量或赛事减量处方。设备数据、历史聊天、自由文本偏好笔记和模型推断均不自动升级为已确认喜好。安全规则始终覆盖偏好。
