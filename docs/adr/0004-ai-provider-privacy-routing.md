# ADR 0004：AI Provider 隐私路由与审计

## 状态

已采纳。

## 决策

所有模型通过 `ModelProvider` 端口接入。调用前由应用层同时检查用户同意、隐私模式、成本上限和证据白名单；调用后记录最小化 `ModelRun` 元数据。没有外部授权、成本超限、网络失败或 Provider 不可用时，回退到离线规则引擎。

OpenAI、Anthropic、Gemini 和 OpenAI-compatible 只作为适配器。模型不计算核心指标，也不能修改领域数据。高风险请求始终由确定性规则覆盖；撤回外部 AI 同意后路由器不会发起新的云端调用。

## 理由

- 更换模型不会改变历史记录和确定性指标；
- 敏感数据默认不外发，允许按任务最小化；
- 成本和失败是显式可控状态；
- 输出引用只能指向请求中已授权的证据。

## 结果

Prompt 版本、Provider、模型、成本、证据和安全覆盖状态可以审计；敏感原始 Prompt 默认不持久化。固定评测用例检查事实、安全、纠正和医疗越界。
