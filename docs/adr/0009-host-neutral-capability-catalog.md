# ADR 0009：用统一能力目录组织对话入口

- 状态：已接受（本地第一版）
- 日期：2026-10-27

## 背景

本地 MCP 已能在 Codex 中调用同步、报告、目标和计划，但其余已实现产品能力仍主要散在 CLI 中。继续逐宿主复制提示词或训练逻辑会导致行为不一致，也容易让模型获得文件路径、凭据或删除权限。

## 决策

所有产品能力先归入 `interfaces/host/catalog.py` 的版本化目录，再按风险决定是否映射为 MCP 工具。模型宿主只负责自然语言编排；MCP 负责输入校验、最小化结果和传输；`interfaces/host/` facade 组合 `application/` 用例；领域规则和私有仓储保持唯一。CLI 可保留不同的运维视图，但不复制训练算法。

能力分四类：

1. **只读查询**：档案摘要、同步状态、活动摘要、数据质量、报告、目标、计划、成长历史、通知和引导状态。
2. **纯计算预览**：恢复评估、一般补给、用户提供赛事详情的离线策略、样本相关性；不写入私人库。赛事输入明确标为未核验。
3. **受确认保护的写入**：目标和训练计划使用持久化草案、版本与确认；Check-in 使用档案绑定的内容摘要预览及确认；标记通知与手动同步仅在用户明确请求时使用，并在本地宿主按写入工具审批。
4. **仅本机管理**：Garmin 登录/撤回、任意文件路径导入、导出、备份、恢复、删除、后台安装/卸载和策略配置暂不提供给模型。它们继续通过本机 CLI/安装流程处理。

`get_capability_catalog` 让宿主发现当前真正可用的能力和本机管理边界。MCP `initialize.instructions` 给所有宿主提供简短的跨工具安全工作流说明；这不能替代独立真人授权。远程开放写入工具前仍需身份绑定、短时效确认和独立授权机制。

## 后果

- Codex 本地对话可以调用阶段 0–5 中适合对话的核心能力，个人数据库仍留在私有保险库。
- 安全分级是产品契约的一部分，不以“所有 CLI 命令都变成 MCP 工具”为目标。
- 当前目录版本描述能力和映射；统一结果 envelope、持久化新手引导状态机、WorkBuddy/Coze/HTTP 适配与远程授权仍是后续工作，不能声称已完成。
