# ADR 0006：Garmin 中国区使用本地会话，MCP 作为可选桥接

## 状态

已接受，2026-10-26。

## 背景

Garmin 中国区账户不一定可以稳定获得或使用 Personal API Key。现有开源 Garmin MCP 多数仍使用 `python-garminconnect` 登录网页私有接口，MCP 解决的是 AI 工具调用协议，不会自动解决账户区域和认证问题。某些 MCP 发行版仍固定旧版底层库，直接引入会将其版本和工具面暴露给核心采集链路。

## 决策

1. Garmin 中国区主路径直接使用 `garminconnect>=0.3.15,<0.4`，并强制 `is_cn=True`。
2. 首次登录交互式读取邮箱、密码和可选 MFA；不保存密码，只在产品数据目录保存权限受限的中国区会话 Token。
3. 连接器只暴露读取训练和身体数据的能力，不引入底层库的写入、删除或账户设置方法。
4. MCP 作为未来可选的本地 stdio AI 工具桥接，不是同步、标准化或存储的必需运行时。
5. 不把 Garmin 邮箱、密码或 Token 发送给托管 MCP。非官方接口失效时，使用 FIT/TCX/CSV/JSON 文件导入兜底。

## 结果

- 产品可以在没有 Personal API Key 的中国区账户上尝试只读同步。
- AI 协议与数据连接器解耦，未来更换 MCP 不会改变标准数据和领域逻辑。
- 由于使用 Garmin 非官方接口，仍需要真实账户验收、稳健的速率控制、版本升级测试和文件导入兜底。
