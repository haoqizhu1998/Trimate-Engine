# ADR 0005：确定性安全规则与一般健康指导

## 状态

已采纳。

## 决策

疼痛、疾病、日常功能受限、肿胀、恢复异常和负荷突增先经过版本化的确定性规则。规则可以降低负荷、暂停计划、要求重新评估或建议寻求专业帮助。AI 只能解释规则结果，不能降低风险等级或绕过硬约束。

缺失 Check-in 表示“未知”，不能解释为低风险。恢复、营养和赛事建议必须返回数据缺口、不确定性及一般健康声明，不输出诊断、治疗或处方。

## 理由

运动和身体数据存在测量误差，生成模型也可能产生不可靠建议。把安全边界固化在可测试的规则中，可以在离线、模型故障或更换 Provider 时保持一致行为。

## 结果

高风险计划的训练负荷为零或进入保护状态；计划调整保留版本、原因和用户拒绝/回滚能力。持续或严重症状会明确升级到合适的医疗专业人员，而不是由产品自行判断疾病。
