# ADR 0003：版本化标准记录与可替换连接器

## 状态

已采纳。

## 决策

外部数据源只能通过 `DataSourceConnector` 产生 `RawSourceRecord`，不能直接写业务数据库。应用层负责保存按 SHA-256 去重的原始证据、转换为 `CanonicalRecord`、幂等写入、更新游标和报告质量问题。

标准记录使用确定性 ID；来源、更正和派生结果追加保存，不覆盖原始证据。更正通过 `supersedes_id` 建立链，训练计划通过领域 `previous_plan_id` 保留版本和回滚历史。每个记录从第一版携带 `athlete_id`。

## 理由

- Garmin、文件和未来设备接口变化不会侵入领域模型；
- 同一批数据重复导入不会产生重复记录；
- 用户可以追溯结论、纠正异常并恢复历史版本；
- 开源代码不需要包含任何个人数据，其他用户使用自己的本地保险库。

## 结果

SQLite 是当前适配器而不是领域依赖；Raw 数据保存在 Profile 目录，测试只使用合成 Fixture。连接器撤回授权必须删除其区域专用凭据，不得影响其他区域。
